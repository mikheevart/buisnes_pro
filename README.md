# БизнесПро — Корпоративный веб-портал 🚀

Современный, быстрый и безопасный корпоративный сайт, разработанный на стеке **Django + Wagtail CMS** с фронтенд-версткой на фреймворке **UIkit 3**. 

Проект разработан в солидном индиго-стиле и оптимизирован для удобного управления контентом и сбора лидов (заявок на обратный звонок).

## 🛠 Стек технологий

- **Backend:** Python 3.12+, Django 5.x, Wagtail CMS (мощный конструктор страниц)
- **Frontend:** UIkit 3 (кастомная индиго-тема), Ванильный JavaScript (ES6)
- **Библиотеки:** IMask (маски телефонных номеров), Font Awesome / Кастомные SVG
- **База данных:** PostgreSQL / SQLite (в режиме разработки)

---

## ✨ Ключевые особенности и функционал

- 🎨 **Солидный дизайн:** Полностью адаптивный интерфейс с кастомными элементами управления в едином Indigo-стиле.
- 📱 **Интерактивные элементы:** Модальное окно обратной связи UIkit с автоматической JS-валидацией и маской телефона формата `+7 (000) 000-00-00`.
- ⚙️ **Гибкий конструктор (StreamField):** Блог собран на динамических блоках — контент-менеджер может менять порядок абзацев, заголовков, цитат и картинок прямо из админки.
- 🧱 **Каталог услуг:** Архитектура Django-моделей обеспечивает автоматический вывод карточек услуг на основе данных из базы.
- 📊 **Главная страница:** Полноценный Hero-экран с редактируемым из админки фоном, интерактивный блок тарифов (помесячно/за год) и автовывод 3 последних новостей блога.
- 🔒 **Безопасность:** Встроенная защита Django от CSRF-атак, XSS и SQL-инъекций.

## 🚀 Локальное развертывание (Запуск проекта)

1. **Клонируйте репозиторий:**
   ```bash
   git clone [https://github.com](https://github.com/mikheevart/buisnes_pro)
   cd buisnes_pro
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv .venv
   # Для Linux / macOS:
   source .venv/bin/activate
   # Для Windows (CMD):
   .venv\Scripts\activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Выполните миграции базы данных:**
   ```bash
   python manage.py migrate
   ```

5. **Создайте аккаунт администратора:**
   ```bash
   python manage.py createsuperuser
   ```

6. **Запустите локальный сервер разработки:**
   ```bash
   python manage.py runserver
   ```
   Сайт будет доступен по адресу: `http://127.0.0`  
   Админ-панель Wagtail: `http://127.0.0admin/`
